# Flask Course – End-to-End Backend Development & ML Deployment

Throughout this journey, I learned how to build scalable backends, design APIs, work with databases, create dynamic web applications, and finally **deploy a machine learning model using Flask**.
This course helped me stay consistent and improve my understanding of backend development from **zero to deployment**.
---

## Course Modules & What I Learned

### **1. Introduction to Flask**

* Basics of the Flask framework
* Creating routes and handling requests
* Understanding app structure and environment setup

### **2. Dynamic URLs, URL Redirection & URL Building**

* Creating dynamic paths
* Generating URLs with `url_for()`
* Redirecting routes and navigation flow

### **3. Web Forms & Input Validation**

* Using **WTForms** for form handling
* Adding validation for clean and secure user inputs
* Using `validators`, error messages, and flashing messages

### **4. Jinja Templates & Template Inheritance**

* Jinja2 templating engine
* Rendering dynamic content
* Base templates (`base.html`)
* Reusable HTML components using template inheritance

### **5. Databases — SQLAlchemy & SQLite**

* Database connections in Flask
* ORM using SQLAlchemy
* Creating models, relationships, CRUD operations
* Understanding migrations
* Part 1 & Part 2 covered complete database integration

### **6. Cookies**

* Setting and retrieving cookies
* Understanding client-side session management strategies

### **7. Sessions**

* Server-side sessions
* Login persistence
* Secure session handling
